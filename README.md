# 딱! 정해

친구끼리 커피, 간식, 벌칙, 순서를 가볍게 정하는 모바일용 미니게임 모음입니다.

## 실행 방법

`index.html` 파일을 더블클릭하면 바로 실행됩니다. 별도 프로그램 설치, 로그인,
서버 연결이 필요하지 않습니다.

## 포함된 게임

- 돌려돌려 룰렛
- 폭탄 돌리기
- 복불복 카드

참가자와 내기 내용은 세 게임에서 공통으로 사용됩니다. 입력 내용은 현재
브라우저에만 저장되며 외부로 전송되지 않습니다.

## 다른 컴퓨터로 옮기기

`friend-bet-games` 폴더 전체를 ZIP으로 압축하거나 USB, 개인 클라우드로
옮기면 됩니다. `index.html`, `styles.css`, `app.js` 세 파일이 모두 함께
있어야 합니다.

나중에 사이트를 공개할 때는 이 폴더의 파일을 정적 웹 호스팅 서비스에 그대로
업로드할 수 있습니다. 이메일, 비밀번호, API 키는 소스에 포함되어 있지 않습니다.
