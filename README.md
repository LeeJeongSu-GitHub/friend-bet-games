# 딱! 정해

친구들과 커피, 간식, 벌칙, 순서, 팀, 자리와 메뉴를 빠르게 정하고
혼자서 개인 기록에도 도전하는 모바일용 미니게임 모음입니다.

## 실행 방법

`index.html`을 더블클릭하면 기본 게임을 바로 실행할 수 있습니다. PWA 설치와
오프라인 캐시는 HTTPS 또는 로컬 개발 서버에서 활성화됩니다.

```powershell
npm install
npm start
```

실행 후 `http://localhost:4173`에 접속합니다.

- 돌려돌려 룰렛
- 폭탄 돌리기
- 복불복 카드
- 순서 정하기
- 팀 나누기
- 제비뽑기
- 사다리 타기
- 메뉴 룰렛
- 자리 배치
- 선택 토너먼트
- 손가락 뽑기
- 반응속도 대결
- 5초 타이머
- 장애물 피하기
- 10초 연타
- 간식 재료 러너
- 아슬아슬 탑 쌓기
- 몽글 과일 합치기

## 편의 기능

- 참가자 한 명씩 추가 또는 쉼표·줄바꿈 일괄 입력
- 최근 멤버 조합 최대 5개 저장
- 룰렛과 제비뽑기의 연속 당첨 제외
- 결과 공유·복사와 최근 결과 5개 보관
- 개인 기록 결과를 같은 게임·난이도·시드로 재현하는 친구 도전 링크
- 메뉴 룰렛과 토너먼트의 후보 목록 공유
- 같이 하기·혼자 도전 모드와 게임별 카테고리
- 2~5명 멀티터치 손가락 뽑기
- 3점제 2인 반응속도 대결과 부정 출발 판정
- 결과 후 사용자 편집형 랜덤 미션 카드
- 3판·5판 파티 세션과 참가자별 점수판
- 참가자 순서형 5초 타이머와 오차 기록
- 개인 반응속도 최고 기록과 3회 방식 개인 5초 기록
- 10초 연타 횟수·초당 속도·최고 기록
- 시작부터 여러 장애물이 떨어지고 첫 2개 동시 공격은 10초, 안전 통로형 3개 위험 파도는 25초에 보장되는 고난도 개인 생존 게임
- 지상 함정·공중 장애물·연속 웨이브를 판단해 피하고, 보호막·자석·6초 피버로 가속 구간의 고득점에 도전하는 간식 재료 러너
- 어긋난 블록이 실제로 잘려 나가고 퍼펙트 연속 기록과 최고 층수를 저장하는 탑 쌓기
- 같은 과일을 물리 충돌로 합쳐 9단계 과일 왕관 완성에 도전하는 과일 합치기
- 모바일 참가자 설정 접기
- 홈 화면 웹 앱 설치, 새 버전 알림, 앱 바로가기와 오프라인 실행
- 6자리 방 코드·초대 링크로 최대 8명이 각자 휴대폰에서 참가하는 온라인 대결
- 반응속도·5초 타이머·10초 연타·장애물 피하기·간식 러너·탑 쌓기·과일 합치기·초성 퀴즈·상식 퀴즈·가위바위보·텔레파시·그림 맞히기의 준비, 동시 시작, 기록 순위와 재대결
- 퀴즈 최초 버저 잠금·오답 기회 이동·정답 공개·문제 자동 진행·3점 선승제와 가위바위보 비공개 동시 선택·자동 대진 진행
- 5라운드 동시 선택 텔레파시와 출제자에게만 제시어를 공개하는 3라운드 실시간 그림 맞히기
- 온라인 게임 종료 후 결과를 유지한 채 방장만 다음 게임을 선택하고, 참가자는 방장이 시작할 때까지 결과 화면에서 대기
- 방장이 정한 난이도와 라운드 시드를 공유하며, 과일 합치기는 90초 제한으로 진행

참가자, 후보, 내기 내용과 최근 결과는 현재 브라우저에만 저장됩니다. 온라인 방에서는
닉네임과 해당 라운드 기록만 참가 기기끼리 WebRTC로 전달되며 별도 게임 서버에
저장하지 않습니다. 방장 기기가 연결 기준이므로 방장은 대결이 끝날 때까지 페이지를
열어 두어야 합니다.

## 개발과 테스트

도전 링크 파싱은 `challenge-logic.js`, 퀴즈·가위바위보 규칙은
`online-activity-logic.js`, 온라인 방 상태와 WebRTC 통신은 `online-room.js`, 결과 이미지와 다운로드는 `result-share.js`, 설치와 서비스 워커
업데이트 처리는 `pwa-manager.js`로 분리되어 있습니다.

```powershell
npm test
npm run test:e2e
npm run test:all
```

단위·구조 검사는 게임 로직과 UI 계약을 확인합니다. Playwright 검사는 데스크톱과
모바일에서 친구 도전, 온라인 방 생성·동시 시작, 결과 공유·저장, 설치, 매니페스트와
아이콘, 서비스 워커, 오프라인 재접속을 실제 Chromium으로 확인합니다. GitHub
Actions에서도 같은 검사가 자동 실행됩니다.

## 공개

정적 파일만 사용하는 프로젝트이므로 GitHub Pages에서 바로 배포할 수 있습니다.
공개 저장소의 `main` 브랜치 루트를 배포 대상으로 설정하면 됩니다. 이후 개인
도메인을 연결해도 서버 코드나 데이터베이스는 필요하지 않습니다.
