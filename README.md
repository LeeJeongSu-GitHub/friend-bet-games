# 딱! 정해

친구들과 커피, 간식, 벌칙, 순서, 팀, 자리와 메뉴를 빠르게 정하고
혼자서 개인 기록에도 도전하는 모바일용 미니게임 모음입니다.

## 실행 방법

`index.html`을 더블클릭하면 기본 게임을 바로 실행할 수 있습니다. PWA 설치와
오프라인 캐시는 HTTPS 또는 로컬 개발 서버에서 활성화됩니다.

```powershell
python -m http.server 4173
```

실행 후 `http://localhost:4173`에 접속합니다.

## 포함된 게임

- 돌려돌려 룰렛
- 폭탄 돌리기
- 복불복 카드
- 순서 정하기
- 팀 나누기
- 제비뽑기
- 사다리 타기
- 메뉴 룰렛
- 자리 배치
- 선택 토너먼트
- 손가락 뽑기
- 반응속도 대결
- 5초 타이머
- 장애물 피하기
- 10초 연타
- 간식 재료 러너

## 편의 기능

- 참가자 한 명씩 추가 또는 쉼표·줄바꿈 일괄 입력
- 최근 멤버 조합 최대 5개 저장
- 룰렛과 제비뽑기의 연속 당첨 제외
- 결과 공유·복사와 최근 결과 5개 보관
- 메뉴 룰렛과 토너먼트의 후보 목록 공유
- 같이 하기·혼자 도전 모드와 게임별 카테고리
- 2~5명 멀티터치 손가락 뽑기
- 3점제 2인 반응속도 대결과 부정 출발 판정
- 결과 후 사용자 편집형 랜덤 미션 카드
- 3판·5판 파티 세션과 참가자별 점수판
- 참가자 순서형 5초 타이머와 오차 기록
- 개인 반응속도 최고 기록과 3회 방식 개인 5초 기록
- 10초 연타 횟수·초당 속도·최고 기록
- 시작부터 여러 장애물이 떨어지고 첫 2개 동시 공격은 10초, 안전 통로형 3개 위험 파도는 25초에 보장되는 고난도 개인 생존 게임
- 지상 함정과 공중 장애물을 판단해 피하고, 보호막·자석·6초 피버로 고득점에 도전하는 간식 재료 러너
- 모바일 참가자 설정 접기
- 웹 앱 설치와 오프라인 실행

참가자, 후보, 내기 내용과 최근 결과는 현재 브라우저에만 저장되며 외부로
전송되지 않습니다.

## 공개

정적 파일만 사용하는 프로젝트이므로 GitHub Pages에서 바로 배포할 수 있습니다.
공개 저장소의 `main` 브랜치 루트를 배포 대상으로 설정하면 됩니다. 이후 개인
도메인을 연결해도 서버 코드나 데이터베이스는 필요하지 않습니다.
